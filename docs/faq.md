# FAQ

## How do you spell the name of this game?

Martian Café Tuinema Tycoon.
Hence, the code repository of this game is called `MartianCafeTuinemaTycoon`.

## Why does the game beep?

That is the music: the game plays a random beep every time it redraws the screen.

## Can I play the game in my browser?

No. The game was written in C++Builder and only runs on Windows.

## Where do the screenshots come from?

The screenshots are recreated from the game's own bitmaps,
following the drawing code in `MCT1.cpp`.
